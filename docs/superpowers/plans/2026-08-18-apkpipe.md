# APKPipe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, production-ready, automated APK & release downloader (`apkpipe`) pairing RSS parsing, Real-Debrid API un-restricting, headless JDownloader 2 fallback, Nextcloud storage ingestion, Web UI, and native MCP Server, with ≥80% test coverage and GHCR container deployment.

**Architecture:** A lightweight FastAPI + SQLite service that polls RSS feeds (Mobilism), matches apps and high-quality releasers (`[Balatan]`, `[derrin]`, etc.), resolves download mirrors through Real-Debrid (Tier 1) or JDownloader 2 (Tier 2) or Playwright Scraper (Tier 3), extracts APKs to Nextcloud directories, triggers Nextcloud OCC scan, sends Apprise/ntfy notifications, and exposes a Web Dashboard and native MCP Server.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, SQLite (aiosqlite / SQLAlchemy), Pydantic v2, Feedparser, BeautifulSoup4, httpx, Pytest, Pytest-cov, Docker, Tailwind CSS, Alpine.js.

## Global Constraints
- Target Repository: Public repo `spelech/apkpipe` on GitHub.
- Branching Strategy: Atomic commits on feature branch `feat/apkpipe-core`, squashed merge to `main`.
- Minimum Test Coverage: ≥ 80% line coverage enforced in pytest and CI.
- Docker Registry: `ghcr.io/spelech/apkpipe:latest`.
- Homelab Pipeline Port Convention: Pipeline Century Decade in `dev/apkpipe` (e.g. Host Port 8429, Container Port 8000).
